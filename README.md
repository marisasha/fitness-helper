# Pet-проект Fitness helper

Разработчик
«Fitness Helper» — это полнофункциональное веб-приложение, созданное для мотивации и систематизации тренировочного процесса посетителей тренажерных залов. Проект успешно объединяет в себе персональный дневник тренировок и комплексную систему геймификации, превращая индивидуальный прогресс в увлекательный социальный опыт.


# Я выполнил следующие задачи:
-Спроектировал и реализовал масштабируемую архитектуру базы данных 
-Разработал полный набор REST API эндпоинтов с помощью DRF
-Реализовал безопасную аутентификацию на основе JWT-токенов
-Настроил детальную систему прав доступа с использованием встроенных и кастомных классов DRF.
-Активно использовал Django ORM для построения сложных запросов с углубленной фильтрацией.
-Реализовал пагинацию для объемных эндпоинтов.
-Качественно настроил Swagger 
-Реализовал обработку исключений, который перехватывает ошибки и возвращает клиенту структурированные JSON-ответы с понятными кодами и сообщениями.
-Вынес все чувствительные настройки в переменные окружения, используя файл .env 
-Внедрил кэширование в Redis для результатов «тяжёлых» GET-запросов. Спроектировал и реализовал стратегию инвалидации кэша, автоматически очищая соответствующие ключи при определенных изменениях данных .
-Полностью докеризировал приложение для всех сервисов (Django, PostgreSQL, Redis, Nginx). 
-Организовал и провёл деплой проекта на продакшн-сервер


# Созданный функционал веб-приложения:
-Разработал систему регистрации и авторизации на основе JWT-токенов, обеспечивающая быстрый и безопасный вход. Пользователь получает полноценный личный кабинет сразу после регистрации.

-Разработал системы 
1.Планирования и проведения тренировки, а именно создания персональных программ тренировок и их пошагового выполнения с интегрированными таймерами отдыха и визуальными подсказками,
2.Рекомендованные тренировки, а именно алгоритмы, предлагающие пользователям готовые программы, адаптированные под их цели ( похудение, набор массы, выносливость ) и текущий уровень подготовки.

-Разработал комплексную систему статистики: 
1.Общая статистика: Сводка показателей по всем упражнениям.
2.Статистика по тренировкам: Анализ эффективности отдельных занятий.
3.Статистика по упражнениям: Детальная таблица прогресса по рабочим весам и объему для каждого упражнения.
4.Трекер целей и посещений: Возможность поставить цель по количеству тренировок в месяц и наглядный трекер для отслеживания её выполнения.

-Разработал функционал для геймификация и мотивации пользователя:
1.Система «Друзья»: Функционал для добавления друзей, просмотра их активностей, тренировочных программ и прогресса, что создает среду для здоровой конкуренции и поддержки.
2.Публичный рейтинг: Динамическая таблица лидеров, где пользователи могут сравнивать свои достижения с другими. 
3.Система достижений: Механика выдачи именных значков за спортивные успехи.

-Разработал справочные материалы и персонализацию:
1.База инструкций к упражнениям: Встроенная библиотека с описаниями и ключевыми моментами по правильной технике выполнения для минимизации травматизма.
2.Управление персональными данными: Функционал для обновления антропометрических данных , а также тренировочных целей. Это позволяет системе корректировать расчет статистики и персональные рекомендации.


# Итог и результат проекта:
Проект был полностью реализован и доведен до производственного развертывания . В процессе live-тестирования целевой аудиторией «Fitness Helper» получил положительные отзывы от пользователей, активно занимающихся в тренажерном зале. Была отмечена полезность системы трекинга для контроля прогресса и, что особенно важно, мотивирующий эффект геймифицированных элементов — рейтинга, достижений и дружеских сравнений.

# Стэк:
Backend: Python, Django REST Framework 
Frontend: TypeScript, React 
Базы данных: PostgreSQL в качестве основной прод-БД, SQLite для локальной разработки.
Кэширование: Redis
